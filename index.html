Applications

One suite, every screen

Cross-platform apps built with React Native and Expo for iOS, Android, web and desktop — each designed for a specific role.

Apps overview

Responder

For individual personnel: status, calls, chat, PTT voice, shifts and location.

Unit

Shared apparatus device: unit status, crew roles, call details and GPS.

Dispatch

Multi-panel dispatch console with live map, resources, PTT and activity log.

Big Board

Widget-based wall display for stations, EOCs and command vehicles.

Relay

Listen to a scanner or audio feed, detect tones, record audio and dispatch.
