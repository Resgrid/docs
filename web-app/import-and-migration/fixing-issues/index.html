Fixing Issues

Department menu → Import & Migration → (workspace) → Issues

The checks rarely find one problem at a time — usually it is 23 people have a phone number we couldn't read. So the Issues tab groups problems by kind, explains why each matters and how to fix it, and offers one-click fixes for the whole group. Every issue has a stable code (IMP-…) that support can look up; this page lists all of them.

Preview feature

Import & Migration is a Preview feature: it is off by default and Resgrid turns it on per department while it is being rolled out.

## Where to find it
  • The Issues tab of a workspace. Its badge is the number of open blocking issues.
  • Issues to fix on the Overview tab (the five most important groups), the blocked count on each data set, and the Fix issues link on a data set page all open it filtered to that data set.

Filter by Data set and tick Show resolved issues to see what has been accepted or excluded. When nothing is left, the tab shows No issues — Everything we checked is ready to import and a button to Review and import.

## Turning it on

Part of Import & Migration: the Onboarding.MigrationWizard flag on for your department and a department administrator signed in. See Overview → Turning it on.

## How an issue group works

Each group is a panel with:

PartContents
HeadingA severity chip — Blocking, Warning or Note — and the title with the number of open rows, for example 12 dates couldn't be read. The code is shown on the right.
WhereThe data set, the column and the first affected row numbers.
Why and howThe explanation and the fix, in plain words.
ActionsThe fixes that apply to this group (below).

Values from your file are never written into an issue; the rows are named by number.

SeverityWhat it means
BlockingThe rows cannot be imported as they are. Fix them or exclude them — a data set with open blocking issues cannot be approved.
WarningThe rows can be imported, but something will be different from your file (a value left empty, a text shortened). Accept the warning to go ahead, or fix it.
NoteInformation — for example that rows match records that already exist and will be linked rather than added.
## Ways to fix
ActionWhat it doesOffered when
AcceptAccepts a warning or note for every row in the group.Warnings and notes
Exclude these N rowsLeaves the rows out of the import (you are asked to confirm). They can be included again later with Reopen.The issue is on rows
Use this valueReplaces the problem cell in every row of the group with the value you type, then checks the rows again — for example the same station for every row with an unknown one.The issue is on one column of some rows
Ask support about thisOpens the Support tab with the issue code attached.Always
ReopenPuts an accepted or excluded group back to open.With Show resolved issues

Other fixes happen elsewhere:

  • Match columns or values — most value doesn't match and reference doesn't match issues are fixed on the data set's matching pages.
  • Fix the file and upload it again — often quickest for many small problems. Upload the corrected file, then Exclude the old data set on Files & data sets so only the new one is imported.
  • Change something in Resgrid — rename a duplicate record, switch on a module, add custom fields, upgrade the plan.

Every fix re-checks only what it affects, and the counts on the Overview tab update as it finishes. Accepting and excluding are remembered: a re-check does not bring back an issue you have already decided.

## Where issues show up

The Shown as column in the tables below says where you meet each code:

Shown asWhereWhat to do
Blocking, Warning, NoteOn the Issues tab, before approval.Fix, exclude, accept — as above.
Blocking if the field is required, otherwise a warningOn the Issues tab. A required field's value is needed; for an optional field the value is left empty if you accept.Fix, exclude, or accept for optional fields.
File refusedOn the Uploaded files list. The file was not read at all.Fix the file and upload it again.
Upload stoppedWhile uploading, under the upload button. Nothing was stored.Upload again, or fix the file first.
Run statusOn the History tab, next to a run.Mostly nothing — Resgrid retries or waits automatically; some need a new approval.
Row not importedAfter an import, on the rows the import skipped.Check the rows, fix them and import again, or ask support.
Warning after importAfter an import, on the data set.Check by hand; see Verify the result.
Check by handAfter a rollback, on the History tab.Compare the record with your source and fix it in Resgrid.
